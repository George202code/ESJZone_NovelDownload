# 系统代理开关方案

> 需求：是否开启代理由用户确定，避免代理关闭导致每图都经历一次代理超时失败再回退直连
> 日期：2026-08-01

---

## 1. 问题根因

原 `_download_image()` 逻辑：配置了 `image_proxy` 时，**总是先尝试代理**，仅当
`httpx.ConnectError / ProxyError` 才回退直连。

当 Clash 等代理软件未启动，`httpx.AsyncClient(proxy=...)` 会等待连接超时（主
`timeout` 默认 45s~90s）才抛出 `ConnectError`，然后才直连。**每张图都先浪费数十秒
在代理连接上**，插图多的书（如 1781790150，数百张图）整体被拖到极慢。

---

## 2. 解决方案：用户控制"系统代理开关"

新增配置 `system_proxy`（bool，默认 `True`）。当用户显式关闭时，图片下载**直接
直连**，根本不进入"代理→回退"分支，零超时浪费。

与原有"代理不可达自动回退"的关系：
- `system_proxy=True`（默认）+ 代理地址存在 → 走代理；代理临时不可达仍自动回退直连（防御）
- `system_proxy=False` → `effective_proxy=None` → 纯直连，不尝试代理
- 两者互补：开关是"用户明确意图"，回退是"代理开着但临时连不上"的兜底

---

## 3. 改动清单

### 3.1 `core/config.py`
`DEFAULT_CONFIG` 新增：
```python
"system_proxy": True,  # 系统代理总开关：False 时图片纯直连
```

### 3.2 `core/downloader.py`
`Downloader.__init__` 计算有效代理：
```python
if config.get('system_proxy', True) and config.get('image_proxy'):
    self.image_proxy = config['image_proxy']
else:
    self.image_proxy = None
    if not config.get('system_proxy', True):
        self.log.info("🔌 系统代理已关闭，图片将使用直连")
```
两处 `_download_image(...)` / `_download_images_batch(...)` 调用将
`proxy=self.config.get('image_proxy')` 改为 `proxy=self.image_proxy`。

（先前已加的"代理连接 3s 短超时"仍保留，作为代理开着但连不上时的快速失败兜底。）

### 3.3 `main.py`
新增命令行开关：
```python
parser.add_argument('--no-proxy', action='store_true',
    help='关闭系统代理，图片使用直连')
# 解析后：
if args.no_proxy:
    config['system_proxy'] = False
```

### 3.4 GUI（规划中）
设置面板新增 **"系统代理" 勾选框**，绑定 `config['system_proxy']`；
`config.json` 中该键即用户持久化选择。

---

## 4. 验证

```python
Downloader(config={'image_proxy':'...','system_proxy':True}).image_proxy
# -> 'http://127.0.0.1:7890'   （用代理）
Downloader(config={'image_proxy':'...','system_proxy':False}).image_proxy
# -> None                      （纯直连，零超时浪费）
Downloader(config={'image_proxy':None,'system_proxy':True}).image_proxy
# -> None                      （无代理地址）
```

---

## 5. 使用建议

- 代理软件**常开** → 保持 `system_proxy=True`，图片走代理加速
- 代理软件**关闭** → 设 `system_proxy=False` 或运行加 `--no-proxy`，纯直连
- 不确定代理状态 → 保持默认 True（代理临时不可用会自动回退，仅首图慢一点）
